MonitorGetName

Returns the operating system's name of the specified monitor.

Name := MonitorGetName(N)

Parameters

N

Type: Integer

If omitted, the primary monitor will be used. Otherwise, specify the monitor number, between 1 and the number returned by MonitorGetCount.

Return Value

Type: String

This function returns the operating system's name for the specified monitor. The shape of that name is the platform's, not Keysharp's:

PlatformName
WindowsThe GDI display device name, such as \\.\DISPLAY1.
Linux (X11)The XRandR output name, such as DP-1 or eDP-1.
Linux (Wayland)The connector name reported by xdg_output, in the same form.
macOSThe display's localized name.

Note: On a virtual X server with no named output — Xvfb, for instance — there is no platform name to report, and a synthetic display-N is returned instead. The names are always distinct from one another, so they can be used to tell monitors apart.

For a monitor's model and manufacturer rather than the operating system's device name, see the Monitor object.

Error Handling

An exception is thrown on failure.

A ValueError is thrown if N is outside the range 1 to MonitorGetCount. Omitting N, or passing 0, selects the primary monitor and is not an error.
