Pause

Pauses the script's current thread or sets the pause state of the underlying thread.

Pause UnderlyingThreadState

Parameters

UnderlyingThreadState

Type: Integer

If omitted, the current thread is paused immediately: the call blocks there until something clears the flag. Otherwise, specify one of the following values:

1 or True: Marks the underlying thread as paused. The current thread is not paused and continues running. When the current thread finishes, the underlying thread resumes any interrupted function it was running. Once it finishes that function (if any), it observes the flag and enters a paused state. If there is no thread underneath the current thread, this has no effect.

0 or False: Unpauses the underlying thread.

-1: Toggles the pause state of the underlying thread.

Remarks

Note: Pause acts on a thread, either the calling one or the one beneath it. Pausing the whole script is not supported, and there is no tray-menu Pause item. In AutoHotkey v2.1, Pause 1 with no thread underneath pauses the script itself.

Unlike Suspend -- which disables hotkeys and hotstrings -- turning on pause will freeze the thread (the current thread if UnderlyingThreadState was omitted, otherwise the underlying thread). As a side-effect, any interrupted threads underneath it will lie dormant until the current thread is unpaused and finishes.

A paused thread keeps processing messages, so hotkeys and work posted from another real thread still run and can unpause it. ExitApp releases it. Timers are suspended for as long as a thread is paused. Explicitly launched threads such as hotkeys and menu items can still be launched; when their threads finish, the underlying thread is still paused. In other words, each thread can be paused independently of the others.

To disable timers without pausing a thread, use Thread NoTimers.

A script is always halted (though not officially paused) while it is displaying any kind of menu (tray menu, menu bar, GUI context menu, etc.)

The built-in variable A_IsPaused contains 1 if the thread immediately underneath the current thread is paused and 0 otherwise. Writing to it, and to Thread.Paused, sets the same flag Pause 1 sets.

Examples

Use Pause to halt a thread, such as to inspect variables. A paused thread keeps processing messages, so a hotkey can release it.

ListVars
Pause
ExitApp ; This line does not execute until the pause is cleared.

#p::Pause 0  ; Win+P unpauses the thread beneath it.

Press a hotkey once to pause the interrupted thread. Press it again to unpause.

Pause::Pause -1  ; The Pause/Break key.
#p::Pause -1  ; Win+P
