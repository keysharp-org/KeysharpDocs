Export (Removed) [v2.1-alpha.11 through v2.1-alpha.30]

The standalone Export declaration was removed in v2.1-alpha.31. export is now an ordinary identifier except when used as the Export modifier of #Import.

Every global variable, function and class declared directly in a script module is automatically available to wildcard imports, except for names beginning with an underscore. An ordinary imported alias is not automatically re-exported; use #Import Export to forward it.

Default exports no longer exist. An unquoted module name or an alias in #Import binds the module object itself.
